# 问卷设置作为独立后台路由

问卷级设置从 Builder 中剥离，作为现有后台 layout 下的独立 `/survey/:id/edit` 路由；新建问卷也从同一设置页开始，完成设置并创建后才能进入 `/survey/:id/question` 题目编辑。列表提供独立的“设置”和“题目”入口，设置页采用分析页同款单列瀑布流布局。

## Consequences

- 编辑模式的右侧面板只负责当前选中题目或布局元素。
- 配置路由复用同一 Builder store 和保存边界，不产生第二份问卷状态。
- 列表中的设置和编辑是两个独立动作；设置与新建在当前标签页打开，编辑保留独立编辑工作区。
